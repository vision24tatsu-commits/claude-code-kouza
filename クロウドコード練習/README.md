# Claude Code 体験講座

ブラウザだけで Claude Code を使ってみる講座です。インストールは不要です。

## 準備（最初に1回だけ）

1. GitHub のアカウントを作る：https://github.com/signup
2. 自分用のコピーを作る
   - https://github.com/vision24tatsu-commits/claude-code-kouza を開く
   - 緑の「Use this template」→「Create a new repository」を押す
   - Repository name に好きな名前（例：`my-kouza`）を入れて「Create repository」を押す
3. https://claude.ai/code を開いて、Claude のアカウントでログインする
4. 画面の案内に従って GitHub と連携し、2で作ったコピーを選ぶ
   - 初めてのときは「Claude の GitHub アプリをインストールしますか？」という画面が出ます
   - インストールするとき、使うリポジトリを聞かれたら、2で作ったコピーを選んでください

## このフォルダの中身

| ファイル | 内容 |
|---|---|
| `memo.txt` | 誤字だらけの連絡メモ |
| `sales.csv` | 3か月分の果物の売上データ |
| `average.py` | バグがある平均点のプログラム |

## 課題

下の「頼み方の例」を、そのまま Claude に送ってみましょう。

### 課題1：中身を見てもらう

> クロウドコード練習フォルダに何が入っているか説明して

### 課題2：文章の誤字を直す

> クロウドコード練習/memo.txt の誤字を直して

直す前と後で、どこが変わったかも聞いてみましょう。

### 課題3：データを集計する

> クロウドコード練習/sales.csv を月ごと・商品ごとに売上金額（数量×単価）を集計して、結果を summary.md に書いて

### 課題4：プログラムのバグを直す

> クロウドコード練習/average.py を実行すると平均点がおかしい。原因を調べて直して、実行して確認して

正しい平均点は 70.0 です。

### 課題5：新しいものを作る

> クロウドコード練習 フォルダに、じゃんけんゲームを Python で作って、遊び方も教えて

### 課題6：GitHub で確認する

> ここまでの変更をコミットしてプッシュして

GitHub のページを開いて、ファイルが本当に変わっているか確かめましょう。

**変更が見えないときは：** Claude は、`main` ではなく `claude/` で始まる作業用のブランチにプッシュします。GitHub のページの左上にある「main」と書かれたボタンを押して、`claude/` で始まるブランチに切り替えると、変更が見られます。

## うまく頼むコツ

- **どのファイルか**をはっきり書く（「直して」より「memo.txt の誤字を直して」）
- **どうなればいいか**を書く（「平均点が 70.0 になるように」）
- 分からないことは、そのまま Claude に聞いてみる（「今なにをしたの？」）
